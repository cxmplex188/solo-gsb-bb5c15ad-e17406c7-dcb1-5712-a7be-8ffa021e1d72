# 折页小册子在线拼版工具

供社区印刷点使用的网页工具：上传一份**按阅读顺序排列**的多页 PDF，选择**每帖 1 张或 2 张纸**，系统自动生成 **A4 横向、双面、短边翻转打印**的拼版 PDF。每张纸正反两面各放两页，等比缩放、逐张对折并按帖套叠后，页码自然连续。

## 功能

- 浏览器上传 PDF（点击选择或拖拽），选择每帖纸张数：
  - **每帖 1 张纸**：每帖 4 页，单张对折，适合薄册子；
  - **每帖 2 张纸**：每帖 8 页，两张嵌套对折，适合较厚册子。
- 按**原页顺序分帖**；页数不足一帖时，**仅在末帖末尾补空白页位**，空白位置不绘制任何内容。
- 输出 A4 横向（841.9 × 595.3 pt）拼版 PDF：每面左右两页，等比缩放并居中。
- 页面展示每帖、每张纸**正面/背面的左右页码与空白位置**，并提示短边翻转与折叠方式。
- 一键下载拼版结果（结果在服务器内存中保留 10 分钟）。

## 拼版排列规则

每张纸在 PDF 中按「正面、背面」相邻输出，双面打印后逐张配对：

| 帖型 | 纸张 | 正面（左 / 右） | 背面（左 / 右） |
| --- | --- | --- | --- |
| 1 张/帖（4 页） | 唯一张 | P4 / P1 | P2 / P3 |
| 2 张/帖（8 页） | 外张 | P8 / P1 | P2 / P7 |
|  | 内张 | P6 / P3 | P4 / P5 |

多帖时按原阅读顺序依次分组（第 1 帖 = 第 1～4k 页，依此类推），不足整帖的页放在最后一帖并在末尾补空白。
打印时选择 **双面 · 短边翻转（沿短边翻页）**，纸张沿中线竖折、按帖套叠装订即可。

## 快速开始（单条命令）

### 方式一：Docker Compose（推荐）

```bash
docker compose up --build -d
```

### 方式二：本地 Node.js（一条命令完成依赖安装与启动）

```bash
npm install && npm start
```

启动后访问：**http://localhost:3000**

- 默认端口 **3000**，可用环境变量修改：`PORT=8080 npm start`，或修改 `docker-compose.yml` 中的端口映射。

停止 Docker 方式：

```bash
docker compose down
```

## 使用步骤

1. 打开 http://localhost:3000 ；
2. 选择按阅读顺序排好页的 PDF（第 1 页为封面）；
3. 选择每帖 1 张或 2 张纸，点击「生成拼版 PDF」；
4. 核对页面上的帖/张/正反面页码预览（灰色虚框为空白）；
5. 点击「下载拼版 PDF」；
6. 打印设置：**A4、横向、双面、短边翻转**；沿每张中线竖折，按帖套齐装订。

## 技术栈

- Node.js + Express（Web 服务与原始 PDF 字节上传）
- [pdf-lib](https://pdf-lib.js.org/)（纯 JS 解析与拼版生成）
- 原生 HTML / CSS / JavaScript（无前端构建步骤）
- Docker / Docker Compose 部署

## 项目结构

```

│   └── pdf.js             # pdf-lib 生成 A4 横向拼版 PDF
├── public/
│   ├── index.html         # 页面
│   ├── styles.css         # 样式

├── docker-compose.yml
└── package.json
```

## 测试

```bash
npm test
```

测试包含：固定样例排列、P=1～40 全部页码落位穷举校验、物理折叠阅读顺序模拟，以及真实生成 PDF 的尺寸与 HTTP 全流程验证。

## 说明与限制

- 上传 PDF 上限 100 MB、页数上限 500；拼版结果仅在内存暂存 10 分钟，重启服务即清空。
- 页面按等比缩放（contain）放入每面的半区并居中，源页非标准比例时四周留白属正常现象。
- 加密且需要口令才能打开的 PDF 无法处理；仅有权限限制（空口令）的 PDF 可正常读取。
